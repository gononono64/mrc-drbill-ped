# mrc-drbill-ped

Dr Bill for FiveM. **Version 1.0.0 · No dependencies.**

![Dr Bill in FiveM](docs/preview.gif)

## Install

1. Download **Code → Download ZIP**, extract it, and rename the folder to `mrc-drbill-ped`.
2. Drop it into your server's `resources` folder. Add this to `server.cfg`:

   ```cfg
   ensure mrc-drbill-ped
   ```

3. Restart your server. Use **`drbill`** as the model name in your admin menu or any resource that changes player peds.

That's it. No framework setup or extra scripts needed.
